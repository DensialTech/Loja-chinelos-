# Loja de Chinelos — Densial Tech

Base de e-commerce da Densial Tech para uma loja de chinelos, desenvolvida com Next.js, React, TypeScript, Tailwind CSS e Supabase.

## Base técnica

Este projeto será baseado no template open source `tarektech/ecommerce-supabase-Nextjs` e evoluído para uma arquitetura de e-commerce reutilizável pela Densial Tech.

## Objetivos

- Catálogo de produtos
- Variantes por tamanho/cor
- Controle de estoque por variante
- Carrinho e checkout
- Pix e cartão via gateway de pagamento
- Pedidos e acompanhamento de status
- Painel administrativo
- SEO e performance
- Estrutura preparada para futuras lojas/clientes

## Princípios de desenvolvimento

1. GitHub como fonte principal do código.
2. Alterações pequenas, revisáveis e testáveis.
3. Separação entre UI, hooks, serviços e dados.
4. Segurança com Supabase RLS e validação de dados.
5. Evitar dependências e serviços pagos sem necessidade.
6. Nenhum uso de créditos/agentes do Lovable sem autorização explícita.
